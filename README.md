# NLPApp – Natural Language Processing Application

NLPApp is a Python-based desktop application developed using Tkinter. It provides a graphical user interface for user registration, login, and accessing different Natural Language Processing (NLP) functionalities.

The project is part of my learning journey in Python, Data Science, and Artificial Intelligence.

## Features

- **User Registration:** Allows new users to create an account.
- **User Login:** Provides authentication using email and password.
- **Home Dashboard:** Displays available NLP functionalities.
- **Sentiment Analysis:** Provides an interface to analyze the sentiment of user-entered text.
- **Named Entity Recognition (NER):** Includes an interface entry point for future entity extraction functionality.
- **Emotion Prediction:** Includes an interface entry point for future emotion prediction functionality.
- **GUI Navigation:** Allows users to navigate between login, signup, and application screens.

## Technologies Used

- Python
- Tkinter – Graphical User Interface
- Database integration through a custom `Database` class
- Natural Language Processing concepts

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/NLPApp.git
```

### 2. Navigate to the project directory

```bash
cd NLPApp
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

Windows:

```bash
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

Tkinter is included with many standard Python installations. Database and NLP dependencies should be added according to the actual implementation.

### 6. Run the application

```bash
python main.py
```
